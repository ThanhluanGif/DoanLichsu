# C-157 — Fail-closed validator cho independent-security handoff

status: done
deps: C-083, C-156
implements: infra

## Scope

Create a deterministic handoff validator for the external `independent-security`
gate. It must require an independent-review scope covering auth/RBAC, source
ingestion and AI safety, tested commit, tool/version, review timestamp, findings
counts and remediation status, plus a named reviewer authority and an existing
SHA-256-matched report artifact. It must reject Critical/High findings, path
traversal, PII/secret values and self-asserted approval. A structurally complete
synthetic packet may pass the schema, but `officialSecurityEvidence=false`,
`releaseAllowed=false` and `publicBeta=false` must remain immutable.
