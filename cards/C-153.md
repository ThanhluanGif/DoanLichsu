status: todo

## Scope

Create a manifest validator for the future official production handoff. It must
require a real HTTPS origin, release commit, image digest, six critical route
checks, rollback/deployment/monitoring artifact hashes, database strategy,
RPO/RTO, named owner/on-call fields and secret *names* without accepting secret
values. A missing or placeholder target must return `BLOCKED_EXTERNAL` and never
be interpreted as production evidence. A fully populated manifest may return
`PASS_HANDOFF_READY`, but the report still keeps `officialProductionEvidence`
false until an authorised external evidence packet is attached.
