# C-069 — Wikimedia Commons 300-record metadata pilot

status: done
deps: [C-042, C-068]
implements: [wikimedia-pilot]

## Scope

Gọi MediaWiki API theo batch bounded để nhập metadata của 300 file Commons vào review queue.
Không tải binary, không auto-publish, không tự đổi rights decision; record thiếu/không rõ vẫn
`LINK_ONLY` và `PENDING_REVIEW`. Lưu revision, artist, credit, license, URL và checksum của
metadata để reviewer/legal xử lý sau.

## Allowed files

- `scripts/wikimedia-import.mjs`
- `scripts/wikimedia-batch.mjs`
- `artifacts/wikimedia/**`
- `cards/C-069.md`

## Verify (run these before calling the card done)

- [x] Every record has page/revision/source/license fields (nullable where API lacks data),
