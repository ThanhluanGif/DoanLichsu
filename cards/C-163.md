# C-163 — Publish immutable production image to GHCR

status: done
deps: C-162
implements: infra

## Scope

Add a GitHub Actions workflow that builds the committed Docker image and pushes
an immutable SHA-tagged image to GitHub Container Registry on `main`, using the
repository-scoped `GITHUB_TOKEN` with `packages:write`. The workflow must emit
the image digest in the Actions summary and retain a short-lived digest artifact
for the future production owner. It must not deploy a service, claim an official
production URL, expose secrets, seed demo data or enable Public Beta.
