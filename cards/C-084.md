# C-084 — Add bounded HTTPS performance observation probe

status: done
deps: [C-083]
implements: [infra]

## Scope

Add a bounded, read-only HTTPS performance probe for health and public search. It
records request latency samples, p50/p95/max, status failures and concurrency,
with a configurable request cap. It must reject non-HTTPS origins and explicitly
mark the result as production-like observation rather than official load/uptime
evidence.
