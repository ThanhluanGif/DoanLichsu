# C-016 — Danh mục nội dung theo loại nối từ trang chủ

status: done
deps: [C-015]
implements: none

## Scope

Biến bốn số liệu Thời kỳ/Sự kiện/Nhân vật/Hiện vật trên trang chủ thành liên kết tới
danh mục công khai song ngữ theo loại tại `/{locale}/{kind}`; cùng route này hỗ trợ cả
Chủ đề khi đi từ breadcrumb detail hoặc sitemap. Mỗi danh mục dùng `GET
/api/v1/{locale}/contents` đã có, chỉ hiển thị bản dịch published, phân trang ổn định,
đổi locale giữ đúng loại và breadcrumb detail quay về đúng danh mục. Tái sử dụng pattern
listing/content-card đã duyệt ở C-001; không thêm API, shape, admin, schema dữ liệu hay
JavaScript client mới.
