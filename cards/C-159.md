## Scope

Create a read-only validator for the canonical published-history reviewer
packet. It must verify the packet SHA-256, exactly 105 unique published content
rows, the expected pending/reviewed counters, bilingual/source/claim readiness
fields and a valid attestation shape for any row already reviewed. It must
reject duplicate IDs, packet hash drift, partial reviewer evidence, fabricated
reviewers, Council self-approval and `publicBeta=true`. The canonical packet
must remain `REQUIRES_HUMAN_REVIEW` with zero database writes until real
authorized reviewers use the existing history-review API.
