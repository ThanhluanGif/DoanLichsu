status: done

## Scope

Add a read-only admin API and review page for the published-history queue. The
queue must list published content lacking `content.editorial_history.review`,
include content version and existing provenance fields, support pagination, and
link each row to the single-record attestation workflow. It must not create
audit rows by listing or viewing the queue.
