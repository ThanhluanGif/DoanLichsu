# C-156 — Fail-closed validator cho DPIA/privacy handoff

status: done
deps: C-048, C-155
implements: infra

## Scope

Create a deterministic DPIA/privacy handoff validator. It must bind the packet
to the canonical `docs/privacy/dpia.md` SHA-256 and verify all eight existing
privacy/child-safety controls, reject policy hash drift, path traversal and
secret/PII values, and preserve the explicit pending-review state. A valid
controls packet may return `PASS_DPIA_CONTROLS_PENDING_REVIEW`, but the report
must keep `approved=false`, `releaseAllowed=false` and `publicBeta=false`; the
validator cannot manufacture a privacy reviewer, legal approval or DPIA sign-off.
