# C-082 — Add fail-closed external evidence pack verifier

status: done
deps: [C-081]

## Scope

Add a deterministic verifier for the external-evidence ledger. It checks the fixed
gate inventory, rejects unknown statuses or fabricated personal-data flags, and
requires every `PASS` item to name a repository-relative artifact, owner and
SHA-256 that matches the artifact on disk. Pending external evidence remains a
valid honest state, while the verifier never promotes it to Public Beta.
