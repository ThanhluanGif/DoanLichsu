# C-092 — Make current release evidence source-tree coherent

status: done
deps: C-091
implements: infra

## Scope

Replace the current-head release evidence's mutable exact-HEAD-only binding with a
deterministic source-tree SHA-256. The evidence script must record both the commit
observed when the run starts (`testedCommit`) and the source-tree hash used for
coherence; the report and regression test must verify that the checked-out source
tree still matches. Exclude only generated release reports, planning artifacts,
and the generated `next-env.d.ts` from this source hash so committing evidence or
running a Next build cannot invalidate its own proof. Preserve explicit disclosure
that the run is local production-like and not official production.
