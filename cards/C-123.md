# C-123 — Add human-reviewed published-history attestation endpoint

status: done
deps: C-122
implements: infra

## Scope

Add an authenticated ADMIN/REVIEWER endpoint that lets a human attest to the
editorial history of one already-published content record. The endpoint must
require the current content version, a non-empty evidence locator, a review
note, and an explicit attestation value; it writes one sanitized audit event
with actor and timestamp, rejects drafts/duplicates/stale versions, and never
backfills or auto-approves records.
