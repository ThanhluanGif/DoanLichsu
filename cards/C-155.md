status: done

## Scope

Create a deterministic validator and handoff protocol for the external
`model-comparison` gate. It must require the same frozen 500-question dataset
and SHA-256, exactly two distinct declared provider/model identities, complete
accuracy/citation/refusal/injection-leak/latency/cost metrics for both, and
artifact paths with matching hashes. It must reject same-model comparisons,
missing metrics, dataset drift, path traversal and secret/token values. A valid
synthetic packet may be structurally ready, but the report must keep
`officialModelIndependenceEvidence=false`, `releaseAllowed=false` and
`publicBeta=false` until a real owner/authority/evidence packet is attached.
