# C-137 — Ship privacy-safe public correction intake

status: done
deps: C-136

## Scope

Implement the first vertical slice of the year-one correction workflow: a
public bilingual form and `POST /api/v1/corrections` that accepts a factual,
source, translation, accessibility, safety or rights report for a published
content item. Store only minimum non-PII moderation data in SQLite, apply
validation, a honeypot and aggregate rate limiting, return a receipt/SLA, and
leave moderation/public changelog transitions for a later card. Amend the PRD
and contract before code so the interface is explicit.
