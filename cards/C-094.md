# C-094 — Gate malformed Wikimedia metadata before rights review

status: done
deps: C-093
implements: infra

## Scope

Add a deterministic metadata-quality gate to the Wikimedia rights-review ledger.
Every imported row must retain a page identifier, file title, description URL,
revision identifier, and revision timestamp before it can be considered reviewable.
Malformed rows must be reported as `INVALID_METADATA`, remain link-only, and keep
binary serving disabled. The real existing batch must be re-evaluated so its report
surfaces any malformed records without inventing replacements or rights decisions.
