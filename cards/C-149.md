## Scope

Build a deterministic, read-only reviewer packet for all currently published
content nodes. Each row must include the content/version identity, both bilingual
locales and their translation statuses, available verified source/claim locators,
current editorial-history status, and
explicit fields for a real reviewer to complete. The packet is a handoff aid for
the 105 missing human attestations; it must never create audit rows, fabricate
reviewer identities, or change the DoD/Public Beta state. Refresh the Global Build
Master and release transparency artifacts so the packet is discoverable and its
SHA-256 is recorded.
