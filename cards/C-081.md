# C-081 — Add fail-closed HTTPS uptime observation probe

status: done
deps: [C-080]
implements: [infra]

## Scope

Build a production-handoff HTTPS observation probe that samples the public health
and OpenAPI endpoints, records every response with timestamp/latency, computes an
availability ratio, and fails closed on non-HTTPS origins, malformed responses or
failed checks. The report must identify its observation window and explicitly state
that a short run is not 90-day uptime evidence.

## Done-evidence (world-state proof, named BEFORE building)

On an HTTPS release-like URL, the command produces a timestamped observation report
with health/OpenAPI status, latency and a computed availability ratio. The report
is usable as an input to the 90-day monitor, while remaining honest that a two-sample
run is not itself the required 90-day uptime evidence.
