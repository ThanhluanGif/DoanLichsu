# C-144 — Validate external evidence packets before release intake

status: done
deps: C-143
implements: infra

## Scope

Add a read-only, fail-closed validator for the external evidence ledger and
reconcile the release snapshot after the new validator lands. It
must accept the current pending handoff without inventing a person or approval,
and must reject a claimed `PASS` packet unless it contains a named owner,
authority scope, verification timestamp, repository-relative artifact and a
matching SHA-256. It writes only a derived validation report; it never mutates
the ledger, database or DoD status. Document the packet shape so real
operations, Council, rights, privacy, pilot and security owners can attach
authoritative evidence later. The Global Build Master and derived release
artifacts must point to the exact new source tree after this change.
