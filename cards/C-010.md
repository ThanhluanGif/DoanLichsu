# C-010 — Phản hồi vi mô cho thao tác công khai

status: done
deps: C-009
implements: none

## Scope

Thêm micro-interaction nhất quán cho button/link control, bộ lọc và thao tác sao chép liên kết trên public site: hover chỉ nâng tối đa 1 px trên thiết bị hỗ trợ hover, press phản hồi tức thời, focus-visible giữ nguyên rõ ràng, và copy-link có trạng thái xác nhận ngắn. Chỉ animate màu, border, shadow, opacity và individual `translate`; keyboard Enter phải kích hoạt copy như click, `prefers-reduced-motion: reduce` tắt animation/transition hoàn toàn trong public subtree, còn admin UI, route reveal và API contract không đổi.
