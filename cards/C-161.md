## Scope

Create a deterministic, read-only production configuration preflight for the
Docker release handoff. It must accept only an official HTTPS `APP_ORIGIN`, an
absolute database path, a non-placeholder `SESSION_SECRET` of at least 32
characters, `NODE_ENV=production`, and demo seeding disabled. It must reject
localhost/example/trycloudflare origins, placeholder secrets, relative paths,
missing required variables and secret values in the report. The preflight must
never deploy, mutate the database, create an owner or promote Public Beta; it
only proves that a future operator-supplied production environment is
structurally safe to hand to the existing production-handoff validator.
