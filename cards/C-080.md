# C-080 — Add editor claim/evidence and source-verification workflow UI

status: done
deps: [C-079]
implements: [claim-evidence-workflow]

## Scope

Expose the already-contracted claim/evidence and source-verification APIs in the
authenticated editorial UI. Editors must be able to create a bilingual claim
with a source locator and submit it for review; Reviewers/Admins must be able to
send a source through verification and verify a claim only when its evidence
source is verified. The UI must show fail-closed errors and verification status.
