## Scope

Add a GitHub Actions workflow that runs the existing HTTPS uptime probe on a
schedule and on manual dispatch. It must read `PRODUCTION_ORIGIN` from an
operator-supplied repository secret, reject missing/non-HTTPS/local/tunnel
origins before probing, upload each probe report with a 90-day retention target,
and never write to the external evidence ledger or enable Public Beta. Extend
the operator runbook and add a focused test that locks the fail-closed workflow
contract.
